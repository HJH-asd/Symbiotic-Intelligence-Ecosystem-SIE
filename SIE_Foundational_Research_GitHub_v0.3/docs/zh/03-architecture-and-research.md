# 03 — 候选架构与研究计划

## 分层结构（提议，尚未实现）

**知识层：** 开放、可版本化、可归属的主张，区分假设、证据和价值偏好，支持双语与机器可读格式。

**智能体层：** 能力、目标和权限不同的人类及机器参与者，不预设其具有相同的道德地位。

**资源层：** 透明的资源约束、合法的多元供给渠道、备用能力和安全降级机制，而非越权扩张。

**协调层：** 互操作协议、协商、有限授权、独立争议渠道，以及条件允许时可撤销的承诺。

**纠错层：** 审计、竞争性方案、受控试验、效果测量、安全迁移、回滚和组织问责。

**安全层：** 最小权限、建议与执行分离、独立监测、隔离与恢复。思想开放不意味着系统访问权限无限开放。

## 纠错闭环

观察 → 可独立检验的诊断 → 多个备选干预 → 风险与权利审查 → 经授权的有限实验 → 测量 → 采用、修订或回滚。

除了纠错耗时，还应衡量准确性、附带伤害、可逆性、合法性以及转型成本由谁承担。

## 对照研究

在相同资源预算和外部冲击下，将SIE启发的机制与集中式管理、市场竞争协调、多中心治理比较。设置合作型、机会主义型、有限理性等不同代理策略，并改变匮乏程度与权力分布。预先登记假设，公开零结果和负结果。

候选指标：关键功能连续性、合作稳定性、资源集中度、退出可行性、纠错速度与准确性、可行策略多样性、冲击后恢复、人权及安全违规、协调成本。

## 优先研究问题

1. 可信的退出机制能否减少强制控制，同时保持集体可靠性？
2. 合作在什么资源压力阈值下瓦解？哪些保障会改变阈值？
3. 管理者自身地位受到威胁时，能否安全报告和纠正错误？
4. 多样性何时增加韧性，何时增加成本和脆弱性？
5. 能否在不中断关键服务的情况下替换强势协调节点？
6. 如何使公共知识库抵御俘获、错误信息和过早共识？

## 与DEKS的关系

DEKS是跨模型、跨工具记录问题、假设、预测、测试、结果和未解决问题的工程工作流程，可作为SIE知识层与纠错层的小规模实验场，但不能证明完整社会架构已经有效。

## 边界与注意事项

使用隔离、抽象的多智能体仿真；不制造自传播恶意软件，不让真实系统遭受未经授权的竞争。涉及真实人员的社会实验需要同意、监督与保障。仿真结果高度依赖代理行为假设，不能直接证明普遍的人类社会规律。
