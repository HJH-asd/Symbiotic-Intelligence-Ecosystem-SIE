# 02 — SIE希望研究和解决的问题

SIE不是万能解决方案。以下是问题类别与**候选**应对机制。

| 问题 | 主要风险机制 | 候选应对方向 | 需要验证的失败情形 |
|---|---|---|---|
| 以生存压力维持控制 | 基本资源与服从绑定 | 多元资源渠道、真实退出、服务连续性保障 | 新基础设施形成新垄断 |
| 蛊式破坏性竞争 | 人为压缩选择空间，奖励掠夺 | 合作激励、替代生态位、公平规则 | 极端匮乏下合作崩溃 |
| 垄断与技术锁定 | 控制算力、能源、标准、数据 | 互操作、可迁移、独立提供者 | 碎片化降低效率和可靠性 |
| 组织纠错失效 | 承认错误威胁地位或生计 | 独立审计、可逆试点、转型保障 | 审计流于形式或被俘获 |
| 相关性系统故障 | 共同模型、供应商或治理节点 | 异构冗余与恢复能力 | 多样性增加复杂度和攻击面 |
| AI资源攫取风险 | 目标与权限鼓励越权获取资源 | 最小权限、安全降级、可问责分配 | 仍然激励隐瞒与规避 |
| AI权力缺乏合法性 | 将能力误认为政治授权 | 人权、同意、可申诉、明确授权 | 治理迟缓或效率下降 |

## 候选设计目标

1. **压力下的合作：** 资源紧张时，合作仍然是一种可行策略。
2. **安全自我纠错：** 不必依赖灾难性崩溃才能发现并修正错误。
3. **避免强制性依赖：** 相互依赖不应自动变成单方面支配。
4. **多样性与可替代性：** 模型、协议、组织乃至SIE本身均可被替换。
5. **开放与安全边界并存：** 开放知识不等于允许入侵、复制或侵占资源。
6. **可问责的治理：** 影响人的决策必须能够质疑并符合合法治理程序。
7. **证据优于教条：** 必须与集中式等替代架构进行实证比较。

## 明确不主张的内容

SIE不承诺消除所有竞争、匮乏、层级、冲突和政治分歧；不预设AI具有意识或与人类完全相同的权利；不宣称去中心化必然优越；不支持故意将真实人员或基础设施置于危险演化压力之中。

## 尚未解决的规范性问题

谁有权获得哪些资源？谁设定安全边界？AI自主性增长时如何保障人权？怎样区分合法集体协调与强制控制？这些问题需要公共治理和社会讨论，不能仅靠技术优化解决。
