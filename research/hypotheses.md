# Testable Hypotheses / 可检验假设

**All entries below are proposals, not established findings. / 以下均为待检验命题，不是既定结论。**

| ID | Hypothesis (English) | 假设（中文） | Possible falsification / 潜在反证 |
|---|---|---|---|
| H1 | Under some scarcity regimes, credible exit reduces coercive control and improves cooperation stability. | 在某些资源紧张条件下，可信的退出机制减少强制控制并改善合作稳定性。 | Exit increases fragmentation without reducing coercion / 退出增加碎片化却未降低强制性 |
| H2 | Safe resource buffers reduce incentives for destructive short-term acquisition. | 安全资源缓冲能够降低破坏性短期攫取的激励。 | Predatory behavior persists at equal or higher rates / 掠夺行为不减反增 |
| H3 | Independent audits plus protected correction pathways improve actual error correction, not just reporting. | 独立审计与受保护的纠错路径能提高实际纠错，而非仅增加报告。 | More reports but no measurable corrections / 报告增加但实际纠错无改善 |
| H4 | Interoperability and replaceability reduce some systemic single-point failures. | 互操作性与可替代性降低某些系统性单点故障。 | Added complexity outweighs redundancy gains / 复杂度代价超过冗余收益 |
| H5 | Under matched conditions, no single governance architecture dominates every efficiency, safety, and adaptability metric. | 在可比条件下，没有一种治理架构在效率、安全和适应性指标上全面占优。 | One architecture consistently dominates across tested regimes / 某架构在测试范围内持续全面占优 |
| H6 | Forced zero-sum selection can reduce viable behavioral diversity despite improving short-run competitive performance. | 强制零和筛选可能在提升短期竞争表现的同时减少可行行为多样性。 | Diversity and long-run adaptability remain equal or improve / 多样性和长期适应性未下降 |

| H7 | Under specified resource shocks, protected exit and reversible policy changes reduce correction latency without increasing serious safety failures. | 在指定资源冲击下，受保护的退出与可逆政策变更降低纠错延迟，且不增加严重安全事故。 | Correction slows or severe failures increase / 纠错变慢或严重故障增加 |
| H8 | Abstract propagation containment plus independent recovery limits digital-to-physical cascading failures better than a single control layer under matched costs. | 在相同成本约束下，抽象传播遏制与独立恢复比单层控制更能限制数字到物理的级联故障。 | No improvement under controlled comparisons / 对照中无改善 |

Each experiment must define agents, incentives, intervention, baselines, metrics, sample size, and sensitivity analysis in advance. / 每项实验应预先定义代理、激励、干预、基线、指标、样本量与敏感性分析。
