# Related Work and Adoption Matrix / 相关研究与吸收边界

**Scope note / 边界：** This is a research map, not an exhaustive systematic literature review. Publication details and links should be checked against publishers before scholarly citation. Some mechanisms below are known from abstracts or accessible public descriptions rather than a full line-by-line replication. / 此表不是系统综述；正式引用前应核对原文和版本，不得把摘要视为实验复核。

| Research / concept | Relevant mechanism | Adoption in SIE | Do NOT infer |
|---|---|---|---|
| Ostrom, *Governing the Commons* (1990) | Institutional diversity, monitoring, nested governance | Strong conceptual foundation for commons and polycentric arrangements | AI/robotic governance already validated |
| Folke et al., *Resilience Thinking* and SES research | Coupled social–ecological feedback, adaptation | **Core system boundary**: include nature as dynamic system | All ecosystems are agents |
| Rockström et al. (2009), planetary boundaries | Biophysical constraints, thresholds | Ecological stress scenarios and constraints | Any single planetary threshold is directly a local engineering quota |
| Masbiole (2006) | Pairwise symbiosis-inspired multiagent learning | Optional **micro-level** testbed; add third-party externalities | Pairwise cooperation ensures ecosystem-wide mutual benefit |
| ISEK (2025), arXiv:2506.09335 | Agent discovery, task coordination, reputation | Optional local coordination protocol; audit lock-in and exclusion | Tokens/one universal protocol are necessary |
| *Symbiotic Alignment via Collective Predictive Coding* (2026) | Coordination without complete homogenization | Candidate cognition/coordination mechanism; track diversity | Alignment solves material dependency |
| *The Formation Mechanism and Configurational Paths of Intelligent Agent Network Ecological Advantages* (2026) | Configurational analysis of resources, governance, adaptation | Compare multiple viable institutional configurations | Observational configurations prove causality |
| *Symbiotic Agents: A Novel Paradigm for Trustworthy AGI-driven Networks* (2025) | LLM + constrained numerical optimization | Useful within DEKS / engineering subsystems | Local performance transfers to global governance |
| *Symbiotic AI and Equitable Digital Health* (2026) | People, technology, community, infrastructure resilience | Example of coupled sociotechnical dependencies | Perspective paper validates SIE |
| Social–ecological systems, ecological economics, Earth-system science | Ecosystems, material flows, institutions, biophysical limits | **Primary cross-system foundations**, not merely analogies | SIE is the first to combine society and nature |

## Practical adoption policy / 采纳规则
1. **Foundational / 基础：** SES, ecological economics, complex adaptive systems, polycentric commons governance, interdependent infrastructure resilience.
2. **Optional local implementations / 局部候选：** MAS rewards, task protocols, reputation, collective prediction, LLM+optimizer.
3. **Experiment-only institutional alternatives / 仅作为对照：** token economies, uniform global identity, centralized authority, universal scoring.
4. **No priority claim / 不主张术语首创：** Related work already uses symbiosis and intelligence-ecosystem terminology.
