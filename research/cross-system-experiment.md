# Cross-System Comparative Experiment v0.1 / 跨系统对照实验草案

**Status:** Proposed, not implemented or validated. / 仅为方案，尚未实施验证。

## System boundaries / 系统边界
Model at least four coupled subsystems: (A) human households/institutions, (B) AI services and robotic production, (C) energy/material/water infrastructure, (D) ecological stocks and regeneration. Affected ecosystems need not act as strategic agents. / 至少包括人类与制度、AI及机器人、能源物质水基础设施、自然生态存量与再生过程；自然生态无需被拟人化。

## Competing governance / 竞争架构
Central allocator; price-based exchange; transferable contribution credits; physical quotas; local mutual-credit/reciprocity; polycentric mixed governance with minimum access and ecological constraints. Each has identical starting resources and exogenous shock schedule. / 统一初始资源和冲击条件，比较集中调度、价格交换、积分、配额、互惠及含基本保障与生态约束的多中心混合制度。

## Interventions / 冲击
- Resource shortfall and asymmetric resource ownership / 资源短缺与所有权不对称
- Failure or capture of a coordinating institution / 协调机构故障或被劫持
- Supply-chain disruption across digital and physical networks / 数字—物理供应链中断
- Ecological lag, threshold and recovery dynamics / 生态滞后、阈值和恢复
- New entrant, provider exit and protocol incompatibility / 新参与者、供应者退出与协议不兼容

## Outcome metrics / 评价指标
Task/service delivery; unmet basic needs; allocation inequality and control centrality; exit and switching cost; audit and correction completion; coordination overhead; ecological stock/functional integrity; irreversible loss; recovery time; strategic/institutional diversity. Report distributional outcomes, not only aggregate means. / 任务供给、基本需求缺口、资源与控制集中度、退出成本、纠错完成率、协调成本、生态完整性与不可逆损害、恢复时间及制度多样性；不能只报告平均值。

## Method safeguards / 方法要求
Pre-register hypotheses and failure criteria; distinguish model assumptions from measured outputs; vary agent strategies and ecosystem response functions; run multiple seeds and sensitivity analyses; use ablations for guarantees, audits, quotas and ecological constraints; publish negative results. Avoid unsafe real-world autonomous propagation or resource acquisition. / 预注册假设与失败条件，区分设定与观测，开展多随机种子、敏感性分析及消融实验；仅在隔离仿真中测试高风险扩张场景。

## Counterexamples / 反证
SIE-inspired arrangements are **not** supported if they consistently increase unmet essential needs, ecological harm, coercive dependency, or coordination failure under comparable constraints, or if a simpler baseline performs better. / 若候选方案在相同约束下持续加重生存缺口、生态损害、强制依赖或协调失效，或简单基线更优，应修订或否定方案。
