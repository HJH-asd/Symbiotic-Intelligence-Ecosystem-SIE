# 08 — 跨智能生态是否需要货币或积分？

**状态：** 开放研究问题，并非主张立即废除货币。

## 先拆分功能
记录焦耳、算力时长、材料与排放量，**不等于**使用可转让的货币。资源分配、交换、激励、储蓄、信誉、争议处理和基本保障可以分别使用不同机制。

| 候选制度 | 可能优势 | 需要检验的风险 |
|---|---|---|
| 可转让货币与价格 | 分散需求表达、跨领域交换 | 财富集中、排斥、外部性 |
| 贡献积分与信誉 | 记录贡献、局部激励 | 刷分、指标劫持、累积优势 |
| 物理预算与配额 | 与真实资源约束直接关联 | 僵化、配额权力集中、隐性成本 |
| 互惠与相互信用 | 不必建立全球货币 | 信任分裂、清算和执行困难 |
| 基本保障加混合分配 | 保障最低需求，其他资源协商 | 保障边界、资金来源、治理劫持 |
| 集中计划 | 有可能协调总体资源优先级 | 信息瓶颈、权力集中 |

**不预设哪种制度必然优越。** 信誉不应自动等于资源购买权；生态完整性也不能全部折算为市场价格。

## 区分三种资源权利
1. **使用权**：为获授权任务消耗有界资源。
2. **请求和协商权**：表达需求并参与资源分配。
3. **控制、积累和转让权**：长期持有资源请求权，甚至排除他人。

这三者不是同一回事。AI 的自治不意味着无限制财产权或对人类及自然生态必需资源的无条件索取权；持有代币也不意味着在单一算力供应商面前拥有真正自主性。

## 自然生态必须进入约束
除任务效率外，还需考察能源、水、土地、开采、排放、生物多样性和栖息地。不可逆或不可替代的损害不能简单用积分补偿，应研究硬约束、监测和代表机制。

## 可证伪假设（尚未证实）
- H-E1：在严重短缺下，仅靠可转让信用的制度可能比含最低保障的混合制度产生更高资源集中度。
- H-E2：若积分忽略生态影响，智能体可能优化积分却破坏生态结果。
- H-E3：局部互惠可保留制度多样性，但互操作性下降时协调成本可能上升。
- H-E4：混合制度在某些韧性指标上可能优于纯集中或纯市场制度，但不会普遍胜出。

应保持参与者、资源预算、环境动力学和冲击条件一致，测量集中度、基本需求缺口、协调成本、决策可逆性、生态损害、恢复能力及退出成本。参见[实验协议](../../research/experiment-protocol.md)。
