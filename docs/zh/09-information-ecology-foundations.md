# 09 — 信息生态理论基础（v0.5）

**状态：探索性理论综合，不是已确立的定理。** 本章扩展 v0.4，不替代治理、自然生态与资源协调的研究议程。

## 1. 信息、结构与载体
信息模式可以跨越物理载体编码、传递和重新实现，前提是相关结构关系在转换中得到保留；信息的实际作用始终依赖物理实现与解释条件。必须区分：(a) 编码符号，(b) 得以保存的关系结构，(c) 特定环境中的因果/操作有效性，(d) 相对于明确任务或目标的价值。这些概念不能直接等同。即使模型文件原样保存，接口、标定、算力或使用权限消失也可能导致其功能失活。

## 2. 身份的多尺度连续性
微观组成不断更替，并不排除宏观组织持续存在。物质连续性、组织连续性、因果过程连续性、法律/社会身份及第一人称经验必须分别研究。AI 状态复制和分叉可以产生具有共同历史的多个后继实例，但不能仅凭功能复制证明唯一的个人身份或主观体验连续性。个体与生态的边界可能随尺度变化，这不意味着可以忽视自主性与权利。

## 3. 多视角与生成能力
具有不同位置、历史和行动方式的主体，可能揭示环境的不同特征。相互作用还可能产生新的仪器、问题、模型、制度和行动方式。副本数量或观点数量本身不能证明这一优势。具有真正独立探索机制的集中式系统可能表现出生态特征；名义上分布式的系统也可能高度同质化并受统一控制。

## 4. 生态信息贫化
扩张性的复制者、垄断机制或过度集中优化，可能挤压其他可执行模型、独立反馈通道、历史档案及实验路径。即使原始数据量或总算力上升，**信息的可用性与未来生成能力**仍可能下降。但不是所有整合都构成损害：淘汰错误认识、消除无效重复也可能提升系统表现。需要在明确的环境分布与资源预算下评估净效果。

## 5. 开放式能力，而非无限多样性
SIE 提出待检验假设：在部分非平稳、未来条件不完全可知的环境中，独立探索、受保护的测试、可逆选择与知识迁移，有利于长期适应。SIE **不主张**生态架构必然优于集中式架构，也不把多样性直接当成具有固定信息论单位的量。严格意义的全知全能者属于哲学极限设定，不能作为经验实验基线。

## 6. 候选因果链
异质主体的情境化互动 → 可独立检验的假设与替代策略 → 可保存、迁移的有效结构 → 环境变化下更广或更稳健的可达能力。该链条是有条件的，存在协调、冲突、冗余成本及错误信息、寄生、控制权俘获和碎片化等失败模式，效应方向与大小必须实测。

## 7. 与既有研究的关系
相关领域包括香农信息论、算法信息、控制论、复杂适应系统、分布式认知、演化理论、韧性工程和多智能体学习。相似性既不证明原创优先权，也不证明经验有效性；更强主张需要逐篇核实的文献对照。

## 8. 安全边界
数字传播风险仅在防御与系统层面讨论，不提供自主复制、漏洞利用或部署操作。人权、同意、隐私、安全和正当治理不能简单还原为信息量最大化。
